# Estudo para imprensa

Material para jornalista, não para seguidor. O leitor é alguém decidindo se aquilo vira pauta.

## O que faz um estudo virar notícia

Três coisas juntas, e a régua honesta é essa: **fenômeno + método + case**.

- **Fenômeno:** algo que está acontecendo no mercado, com dado que sustente
- **Método:** como o cliente enxerga e resolve aquilo
- **Case:** uma empresa concreta, com número liberado

Faltando qualquer uma das três, é release institucional e o jornalista descarta.

## Estrutura

| Parte | Regra |
|---|---|
| Título | O fato, não o adjetivo |
| Lede | Quem, o quê, quanto, quando. O número na primeira linha |
| Contexto | O fenômeno com fonte primária e link |
| Método | O que o cliente faz diferente, em termos verificáveis |
| Case | Empresa, situação, o que foi feito, resultado com número de `provas.md` |
| Citação | Fala nomeada de alguém da casa. Confirmar no `perfil.md` que a pessoa ainda é da casa |
| Sobre | Parágrafo institucional curto no fim, nunca no começo. Sem linha de contato de imprensa nem campo em colchetes para preencher |

## Fontes

Nível mais alto de exigência do catálogo. Jornalista confere. Toda afirmação com fonte primária,
link e data. Secundária serve para achar a primária, não para sustentar.

O mapa de veículos do cliente está no `perfil.md`, seção "Skills e ativos que o motor pluga aqui",
estação 3.

## Recorte do público

Agregado que não descreve quem o cliente atende é erro que jornalista de economia pega na primeira
leitura. Os cuidados de recorte do público estão no `perfil.md` do cliente.

## Vira deck quando

O estudo tiver mais de 5 blocos de dado. Aí entra a skill `pptx` ou de slides, se instalada. A referência de
tamanho do deck do cliente, quando houver, está no `formatos.md`.

## Entregável

`.docx` do estudo, mais o deck quando houver, mais a lista de fontes com links em anexo.
